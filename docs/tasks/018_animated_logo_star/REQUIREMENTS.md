# Задача 018: Анимированный SVG-логотип SFTG AI со скручиванием звезды

## Бизнес-цель
Добавить интеллигентную микроанимацию фирменной звезды в логотипе SFTG AI на сайте, подчеркивающую технологичность и AI-направленность бренда без перегрузки интерфейса.

## Требования
1. Не трогать исходный растровый файл `public/favicon.png`.
2. Компонент `SftgLogo.jsx` перевести на векторный SVG.
3. Сохранить дизайн:
   - Фон: скругленный квадрат `#2997D8`.
   - Буквы: `S`, `F`, `T`, `G` белые, жирные, строго по углам, статичные.
   - Центр: 4-конечная звезда (sparkle).
4. Анимация звезды:
   - Периодичность: цикл 5-6 секунд (большую часть времени звезда статична).
   - Фаза 1: предвосхищение (anticipation) — звезда плавно сжимается к центру (~0.6-0.7 scale).
   - Фаза 2: энергичный поворот по часовой стрелке.
   - Фаза 3: пружинистый отскок (overshoot / pop) — лучи вытягиваются и возвращаются в исходное состояние.
5. Фавикон во вкладке браузера оставить статичным.
