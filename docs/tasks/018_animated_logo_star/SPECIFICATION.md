# Спецификация задачи 018: Анимированный векторный логотип SftgLogo

## Архитектура компонента `SftgLogo.jsx`

Векторная разметка `viewBox="0 0 100 100"`:
- Скругленный прямоугольник: `rx="22"`, заливка `#2997D8`.
- Текст букв в 4 квадрантах:
  - `S`: `x="28"`, `y="34"`
  - `F`: `x="72"`, `y="34"`
  - `T`: `x="28"`, `y="78"`
  - `G`: `x="72"`, `y="78"`
  - Шрифт: `font-family="system-ui, -apple-system, sans-serif"`, `font-weight="800"`, `text-anchor="middle"`, `dominant-baseline="central"`.
- Центральная 4-конечная звезда:
  - Центр `(50, 50)`.
  - Путь звезды: `M 50 16 Q 50 50 84 50 Q 50 50 50 84 Q 50 50 16 50 Q 50 50 50 16 Z`.
  - Мягкое свечение на кончиках.
  - Центр вращения: `transform-origin: 50px 50px`.
  - CSS keyframes:
    - `0%..70%`: `transform: rotate(0deg) scale(1);` (покой)
    - `76%`: `transform: rotate(-15deg) scale(0.65);` (сжатие перед прыжком / замах назад)
    - `88%`: `transform: rotate(375deg) scale(1.15);` (быстрый перекрут по часовой стрелке с вытягиванием кончиков)
    - `94%`: `transform: rotate(358deg) scale(0.96);` (легкая амортизация)
    - `100%`: `transform: rotate(360deg) scale(1);` (фиксация в исходном положении)
