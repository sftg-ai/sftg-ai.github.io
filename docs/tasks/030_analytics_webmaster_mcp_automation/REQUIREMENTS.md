# Task 030: Analytics & Webmaster MCP Automation (Google + Yandex)

> **Статус:** Backlog (запланировано на будущее)  
> **Инициатор:** Александр Кириллов (2026-11-11)

## 1. Бизнес-контекст и цели

В рамках задачи `029` на сайте `softgreat.by` развёрнуты Google Tag Manager (`GTM-TGH2T9G6`), Google Analytics 4 (`G-9W0R6VLBVT`), Яндекс.Метрика (`114182508`), Google Search Console и Яндекс.Вебмастер.

Следующий шаг — избавиться от ручного кликанья в веб-интерфейсах рекламных, аналитических и поисковых кабинетов. Нужно дать ассистенту Antigravity прямой безопасный доступ к управлению и проверке этих систем через официальные API (локальный MCP-сервер).

### Ожидаемый результат
- Настройка Custom Dimensions, Key Events, целей Метрики, новых тегов/триггеров GTM и публикация версий выполняются из Antigravity за 1 команду.
- Автоматическая сквозная проверка, что события с сайта реально долетают в Realtime GA4 и Метрику.
- Получение регулярных отчётов по заявкам, позициям в поиске (GSC / Вебмастер) и ошибкам индексации без захода в 4 разных кабинета.

---

## 2. Функциональные требования

1. **Google API контур (через Service Account / OAuth в GCP):**
   - **Tag Manager API v2 (`GTM-TGH2T9G6`):** чтение/создание/обновление переменных, триггеров, тегов и публикация версий контейнера.
   - **GA4 Admin API & Data API (`G-9W0R6VLBVT`):** создание Custom Dimensions (`channel`, `location`, `source`, `scenarios_count`), отметка Key Events (`lead_form_submit`), чтение Realtime и агрегированных отчётов по конверсиям и источникам трафика.
   - **Google Search Console API (`https://softgreat.by/`):** отправка `sitemap.xml`, чтение статистики поисковых запросов/позиций/CTR и проверка статуса индексации URL.
2. **Яндекс API контур (через OAuth-токен Яндекс ID):**
   - **Яндекс.Метрика Management & Reporting API (`114182508`):** чтение/создание/редактирование целей, выгрузка статистики по визитам, источникам и конверсиям.
   - **Яндекс.Вебмастер API (`softgreat.by`):** отправка `sitemap.xml`, проверка индексации, диагностика сайта и переобход страниц.
3. **Безопасность хранения секретов:**
   - Все JSON-ключи сервисных аккаунтов и OAuth-токены хранятся **строго локально** вне git-репозитория (например, в `~/.config/sftg-analytics-mcp/`).
   - Поддержка режима «только чтение» vs «запись/публикация» (подтверждение перед публикацией изменений в боевой GTM или удалением целей).

---

## 3. Критерии приёмки (на момент будущей реализации)

1. Локальный MCP-сервер подключён к Antigravity и успешно проходит авторизацию в Google (GTM/GA4/GSC) и Яндексе (Метрика/Вебмастер).
2. Ассистент из чата может прочитать текущие теги в `GTM-TGH2T9G6`, проверить цели в счётчике `114182508`, создать недостающие Custom Dimensions в `G-9W0R6VLBVT` и выгрузить отчёт по запросам из Search Console.
3. Ни один секрет или токен не попадает в репозиторий кода.
