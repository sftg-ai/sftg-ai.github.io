> **Эндпоинт:** `https://audit.apps.aipush.dev/api/v1/analyze`

---

## 1. Схема взаимодействия с бэкендом

```
[ Пользователь вводит сайт/компанию ]
                │
                ▼
      fetch(VITE_AI_ANALYSIS_ENDPOINT, {
        method: 'POST',
        body: JSON.stringify({ company, systems, userWish })
      })
      ├── В процессе: цикл смены фаз анализа (каждые 400 мс)
      └── При ответе:
            ├── status === "success" -> рендер персональных карточек
            └── status === "insufficient_data" -> предупреждение + уточнение сферы
```

## 3. Обработка `insufficient_data` в UI

Если сервер возвращает `status: "insufficient_data"`:
- Выводится мягкая информационная плашка:  
  `Не удалось точно определить компанию «asdfdsafg». Показаны базовые сценарии для бизнеса.`
- Появляется кнопка «Уточнить сферу или прикрепить сайт».
