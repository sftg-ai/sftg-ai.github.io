# Task 028: Dual-Mode Visual Pipeline Animations for Hero Scenario Analyzer

## 1. Бизнес-контекст и цели
В рамках задачи экспресс-подбора автоматизации на главной странице (`HeroScenarioAnalyzer`) необходимо заменить стандартный спиннер (`Loader2`) и базовую полоску прогресс-бара на визуальную инженерную анимацию, отражающую технологическую глубину процесса анализа.

Пользователь запускает анализ, и система случайным образом (50/50) активирует один из двух инженерных стилей визуализации:
1. **«Осциллограф процессов» (Process Cardiogram)** — бегущая импульсная синусоидальная волна (пульс сердцебиения бизнес-процессов), которая размеренно идет на этапе сбора данных и резко ускоряется на этапе машинных вычислений.
2. **«Сетевая топология» (Circuit Topology Trace)** — горизонтальная микросхема / трассировка связей между 4 узлами (`Компания` ➔ `Реестры данных` ➔ `1С / CRM` ➔ `Контур решений`), где луч света соединяет узлы по мере прохождения фаз.

## 2. Критерии приемки (Acceptance Criteria)
1. **Рандомизация:** При каждом старте анализа (`handleRunAnalysis`) случайно выбирается один из двух визуальных режимов (`'oscilloscope'` или `'topology'`).
2. **Режим 1 (Осциллограф):**
   - Плавная живая анимация бегущего импульса на SVG-холсте.
   - На первых 3 шагах (сбор данных) частота спокойная (1.5–1.8с на шаг).
   - На шагах 4–11 (машинные вычисления) частота импульсов и амплитуда динамически возрастают, показывая интенсивную обработку.
3. **Режим 2 (Топология):**
   - 4 аккуратных векторных узла в B2B-стиле.
   - Линия-луч последовательно соединяет узлы в соответствии с текущим шагом `analysisStep`.
   - Активный узел плавно подсвечивается фирменным синим цветом `bg-sky-500` / `stroke-sky-600`.
4. **Легковесность и производительность:**
   - 0 КБ сторонних библиотек: только чистый React, SVG и CSS/Tailwind.
   - 60 кадров/сек без просадок и утечек памяти (таймеры/requestAnimationFrame очищаются при смене статуса или unmount).
5. **Дизайн-система:**
   - Строгий стиль Unslop / Light Business.
   - Никаких кислотных или фиолетовых градиентов: палитра `#0284C7` (Sky), `#0F172A` (Slate-900), `#E2E8F0` (Slate-200), `#F8FAFC`.
