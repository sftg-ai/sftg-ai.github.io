# Задача 026: Сквозной префилл и тегирование формы Битрикс24 данными экспресс-анализа

## 1. Бизнес-цель
Обеспечить бесшовный путь клиента от экспресс-анализа в первом экране (Hero) до отправки лида в CRM Битрикс24. Данные, рассчитанные клиентом (название компании, используемые системы, 3 подобранных сценария автоматизации), автоматически передаются в поля формы Битрикс24 с меткой `[Экспресс-анализ SoftGreat AI]`, позволяя клиенту не вводить информацию заново, а лишь дополнить своими комментариями.

## 2. Пользовательский сценарий
1. Клиент в Hero запускает экспресс-подбор и получает 3 сценария.
2. Клиент нажимает кнопку **«Внедрить эти сценарии (Перейти к заявке)»**.
3. Страница плавно прокручивается к форме `#lead-form`.
4. Форма Битрикс24 автоматически заполняется:
   - Поле `Сайт компании или сфера бизнеса` ➔ значение из ввода в Hero.
   - Поле `Ваша задача или комментарий` ➔ структурированный текст с тегом `[Экспресс-анализ SoftGreat AI]`, выбранными системами и списком сценариев.
5. Над формой появляется компактное уведомление: *«Данные экспресс-анализа для [компания] добавлены в заявку — вы можете дополнить их своими комментариями»*.
6. Поле комментария остается полностью редактируемым.

## 3. Критерии приемки
- Интеграция с Bitrix24 JS API (`b24:form:init`, `form.setValues()`).
- Корректная работа как при ранней, так и при поздней загрузке фрейма формы.
- Сборка `npm run build` завершается с кодом 0.
