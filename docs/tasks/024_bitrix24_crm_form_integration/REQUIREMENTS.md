# Задача 024: Интеграция официальной CRM-формы Битрикс24 (Форма №43)

## Бизнес-контекст и цели
Заказчик (Вадим Черкас) передал официальный код инлайн-формы Битрикс24 (форма №43, CRM-лидген) для автоматического попадания входящих заявок с лендинга прямо в пайплайн CRM-системы SoftGreat AI.

## Требования
1. **Нативная интеграция Битрикс24:**
   - Использовать инлайн-виджет с атрибутами:
     - `data-b24-form="inline/43/jps6a7"`
     - `data-b24-form-telemetry-sign="v1:43:site.423e8e2979092b628b864e7b9f98f9f489e3d6b866abe3289cfba0e03246c715"`
     - `data-skip-moving="true"`
     - CDN-скрипт: `https://cdn-ru.bitrix24.by/b33075640/crm/form/loader_43.js`
   - Запасная прямая ссылка: `https://b24-xxbdwe.b24site.online/crm_form_gg1ic/`
2. **Конверсионная структура блока `#lead-form`:**
   - Сохранить левую колонку с ценностным предложением: 3 шага предварительного разбора без составления ТЗ (изучение сайта ➔ гипотезы ➔ созвон 20-30 мин).
   - Справа — нативный контейнер формы в карточке B2B Light Business дизайна (`bg-white rounded-3xl border border-slate-200 shadow-xl`).
3. **Надежность в React SPA:**
   - Отсутствие дублей при перерендерах и навигации по якорям.
   - Минималистичный скелетон/лоадер до момента инициализации скрипта.
4. **Регламент AGENTS.md:**
   - Чистый код, отсутствие технических клише, сборка `npm run build` с кодом 0.
