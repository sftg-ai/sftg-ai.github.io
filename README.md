# SoftGreat AI — Официальный B2B-сайт

> Высококонверсионный технологичный лендинг B2B AI-решений **SoftGreat AI** (ООО «Инновационный Софт», ПВТ, Минск).  
> **Продакшн:** 👉 **[https://softgreat.by](https://softgreat.by)** (зеркало: [https://sftg-ai.github.io](https://sftg-ai.github.io))

---

## 1. Стек технологий

- **Фронтенд:** React 18 + Vite 5 + Tailwind CSS
- **Рендеринг:** SSR Pre-render скрипт для SEO-индексации
- **Иконки:** Lucide React (строгий линейный набор, отказ от эмодзи)
- **Типографика:** Manrope
- **Аналитика и приватность:** GTM, GA4, Яндекс.Метрика с поддержкой Закона Республики Беларусь № 99-З «О защите персональных данных»
- **CI/CD:** GitHub Actions (автоматическая сборка и публикация на GitHub Pages при пуше в `main`)

---

## 2. Быстрый старт

```bash
# Клонирование репозитория
git clone https://github.com/sftg-ai/sftg-ai.github.io.git sftg-site
cd sftg-site

# Установка зависимостей
npm install

# Запуск локального сервера разработки (порт 5173)
npm run dev

# Проверка и сборка проекта для продакшна (включает SSR-пререндеринг)
npm run build
```

## 4. Архитектура и дизайн-система

Интерфейс спроектирован по принципам корпоративного B2B-минимализма:
- **Цветовая палитра:** чистый белый фон (`#FFFFFF`), снежный фон секций (`#F8FAFC`), фирменный синий акцент (`#2997D8` / `#0284C7`), нейтральные границы `slate-200`.
- **Строгий текст:** формулировки на понятном бизнесу языке (сокращение издержек, ускорение регламентов, контроль расхождений) без хайповых клише и шаблонных обещаний.
- **Единая сетка:** двухколоночные десктопные раскладки с левым выравниванием (`max-w-7xl mx-auto px-4 sm:px-6`).
- **Соблюдение Закона № 99-З:** встроенный баннер согласия на обработку файлов cookie с раздельным управлением категориями аналитики.
